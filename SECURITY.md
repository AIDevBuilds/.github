# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.

That creates a private report that only the maintainer can read. If a repository does not show that option, open a
public issue that says only "security contact needed", without any details, and I will set up a private channel.

## Supported versions

Only the latest commit on the default branch of an active repository receives fixes. Archived repositories are
read-only and are not maintained.

## If you find a secret

If you find a key, token or password committed to any of these repositories, please report it the same way. Do not
use or share it.

## What to expect

I read every report and reply when I can. These are personal projects, so there is no fixed response time.
