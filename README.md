# Community files for AIDevBuilds repositories

Default community health files. GitHub uses these automatically for every repository under this account that does
not have its own copy:

- [SECURITY.md](SECURITY.md): how to report a vulnerability privately
- [CONTRIBUTING.md](CONTRIBUTING.md): how to contribute (every pull request needs one approval)
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): expected behaviour
- [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md): the default pull request description

GitHub does not share `LICENSE`, `README.md` or `CODEOWNERS` this way. Each repository keeps its own.
