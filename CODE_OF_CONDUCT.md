# Code of conduct

These repositories are for learning and sharing code. Please keep discussion respectful and about the work.

## Expected behaviour

- Be polite and assume good intent.
- Give feedback on the code or the idea, not the person.
- Keep issues and pull requests on topic.

## Not acceptable

- Harassment, insults or discrimination of any kind.
- Spam, advertising or unrelated promotion.
- Sharing other people's private information.

## Enforcement

The maintainer may edit or remove comments, close issues and pull requests, and block accounts that break these
rules. To report a problem with someone's behaviour, use GitHub's "Report content" option on the comment or contact
the maintainer through the links on the AIDevBuilds profile.
