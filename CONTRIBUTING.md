# Contributing

Thanks for taking a look. Pull requests are welcome on active repositories. Archived repositories are read-only.

## How to contribute

1. Fork the repository and create a branch from the default branch.
2. Keep the change small and focused, with a clear commit message. Commit history is kept as it is, so each commit
   should make sense on its own.
3. Open a pull request and say what changed and why.
4. Every pull request needs one approval from the maintainer before it can be merged. Direct pushes to the default
   branch are not possible.

## Before you open a pull request

- Do not include secrets, keys or personal data.
- Update the README if you change how the project runs.
- Run the project's tests if it has any.

## Licence

By contributing you agree that your contribution is released under the repository's licence (MIT in most
repositories). Check the `LICENSE` file in the repository you are contributing to.

## Questions and ideas

Open an issue in the repository. For security problems, follow the [security policy](SECURITY.md) instead.
